# Overview

I developed the Simple Kotlin Calculator to improve my skills in Kotlin programming and Android application development. My goal was to learn how Kotlin can be used to build a mobile application that performs calculations, handles user input, and manages data.

The Simple Kotlin Calculator is an Android application that allows users to enter two numbers and perform addition, subtraction, multiplication, and division. It displays the result and keeps a numbered history of previous calculations. Users can clear the inputs and result or clear the calculation history. The application also validates user input and handles division by zero.

The purpose of developing this software was to gain practical experience with Kotlin syntax and programming concepts. Through this project, I practised using variables, expressions, conditional statements, loops, functions, classes, and collections. I also gained experience connecting Kotlin code to an Android user interface and testing an application using an emulator.

# Development Environment

I used Android Studio to create, build, and run the Android application. I used Visual Studio Code to edit and organise my Kotlin source files. The Android emulator allowed me to run the application and test its features without needing a physical Android device. I also used the Android SDK and Gradle build system to build the project.

The programming language used was Kotlin. The application uses Android libraries to create the user interface and handle user interactions. The interface was created using XML layouts, while Kotlin handles the calculations, input validation, button actions, and calculation history. I used a mutable list to store previous calculations and a loop to display the history as numbered entries.
